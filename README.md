# NFC Платежная Система (Терминал Продавца + Мобильный Веб-шлюз)

Комплексное решение для приема бесконтактных платежей в Республике Таджикистан через приложения банков:
- 🟢 **Alif Mobi**
- 🔴 **DC Next (Dushanbe City)**
- 🔵 **Банк Эсхата Онлайн**
- 🟡 **Корти Милли / Единый QR НБТ**

## 🚀 Быстрый запуск

### Шаг 1. Запуск веб-шлюза оплаты (Компьютер / Сервер)

1. Откройте терминал в папке `customer-payment-web`:
   ```bash
   cd "C:\Users\Mohchehra\Desktop\nfc-payment-app\customer-payment-web"
   python server.py
   ```
2. В консоли отобразится ваш локальный IP-адрес, например:  
   `http://192.168.1.100:3000`
3. Убедитесь, что телефон продавца и телефон покупателя подключены к **одному Wi-Fi роутеру**.

---

### Шаг 2. Запуск Android-приложения терминала

1. Откройте папку `merchant-android-app` в **Android Studio**.
2. Нажмите кнопку **Run (Shift+F10)** для установки на телефон продавца с поддержкой NFC.
   *(Или соберите APK в терминале: `./gradlew assembleDebug`)*.
3. В приложении в правом верхнем углу (шестеренка ⚙️) укажите IP вашего компьютера, например `192.168.1.100:3000`.

## 💡 Как работает сценарий оплаты

1. **Продавец:**
   - Набирает сумму (например, `50 TJS`) на цифровой клавиатуре приложения.
   - Нажимает **«ПРИНЯТЬ ОПЛАТУ (NFC)»**.
   - Экран терминала переходит в режим ожидания касания.
   - Сервис `NfcPaymentHceService` активирует эмуляцию NFC метки.

2. **Покупатель:**
   - Подносит свой смартфон к задней панели телефона продавца.
   - Смартфон покупателя считывает ссылку `http://192.168.1.100:3000/?order=ORD-XXXXX&amount=50` и мгновенно открывает браузер.

3. **Оплата в 1 клик:**
   - Покупатель видит сумму `50.00 TJS` и нажимает на свой банк (**Alif Mobi** / **DC Next**).
   - Страница запускает банковское приложение через **Deep Link**:
     - Номер счета продавца уже подставлен в поле получателя.
     - Сумма `50.00 TJS` уже заполнена.
   - Покупатель нажимает «Оплатить» и подтверждает операцию (Face ID / отпечаток).

4. **Мгновенное подтверждение:**
   - После подтверждения сервер отправляет сигнал на терминал продавца.
   - Терминал продавца загорается зеленым: **«ОПЛАЧЕНО 50 TJS»**.
